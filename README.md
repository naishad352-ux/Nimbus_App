# Nimbus App - Manual Testing Project

## Project Overview
This project focuses on manual testing of the Nimbus application. The goal was to check the main features, verify input validations, and identify bugs.

## Modules Tested
- Login
- Sign Up
- Forgot Password
- Logout

## Testing Activities
- Prepared test scenarios and test cases.
- Executed test cases and recorded the results.
- Performed positive and negative testing.
- Identified and documented bugs.
- Performed retesting and regression testing.

## Tools Used
- Microsoft Excel
- Google Chrome

## Project Documents
- Test Cases (Excel)
- Test Execution Results (Excel)
- Bug and Summary Report(Word)

## Test Summary
During testing, I identified 5 bugs and documented them in the bug report. I also prepared a testing summary with suggestions for improvement.
